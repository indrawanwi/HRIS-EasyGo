# HRIS EasyGo

A production‑grade Human Resources Information System built with **Next.js 14 (App Router, TypeScript)** and **Neon PostgreSQL** (Drizzle ORM).  

## Features
- Secure authentication via **Neon Auth** (Better Auth SDK).
- Comprehensive master‑data model (organization, employees, contracts, leave, payroll).
- REST API (`/api/v1/*`) for mobile clients.
- Object storage for employee photos and document attachments.
- AI‑gateway integration for smart assistants.
- Automated CI/CD with Vercel preview deployments.

## Getting Started
```bash
# Clone the repo (already done)
cd HRIS-Easygo

# Install dependencies
npm install

# Run a local development server
npm run dev
```

## Scripts
- `npm run dev` – start Next.js dev server.
- `npm run build` – production build.
- `npm run start` – start the built app.
- `npm run test:neon` – smoke tests against Neon services.
- `npm run test:e2e` – end‑to‑end tests with Playwright.
